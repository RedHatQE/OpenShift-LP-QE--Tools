## 2026-09-29
### prow-analyzer — fix container build 401 by switching to public base images
- The `image/container/prow-analyzer/Dockerfile` based both stages on `registry.ci.openshift.org` (`ocp/builder:rhel-9-golang-1.25-openshift-4.22` and `ocp/4.22:base-rhel9`). That registry needs OpenShift CI credentials the GitHub Actions runner does not have (especially on `pull_request`), so the build failed with `HTTP 401` resolving the builder image.
- Switched to publicly pullable Red Hat images: builder `registry.access.redhat.com/ubi9/go-toolset:1.22` (matches `go.mod` `go 1.22`), runtime `registry.access.redhat.com/ubi9/ubi:latest` (closest public equivalent to `base-rhel9`; ships shell/coreutils + CA trust the bot needs for outbound TLS). Build now runs in `/opt/app-root/src` as the non-root go-toolset user (`COPY --chown=1001:0`), builds with `CGO_ENABLED=0`, and copies both binaries into the runtime image.
- ote-plugin Dockerfile intentionally left unchanged: it is built by CI Operator (which resolves `registry.ci.openshift.org` refs with credentials), not by GitHub Actions.
- Verified locally: `podman build` succeeds, `prow-analyzer--cli --help` runs, and `/etc/pki/tls/certs/ca-bundle.crt` is present in the runtime image.

### prow-analyzer — fix queue-full leaving a stale dedup entry
- Bug: the dedup key was recorded before the semaphore was acquired, so a queue-full drop left the key set for the whole window — silently swallowing the retry.
- Fix: `forget(key)` on the queue-full path so retries are treated as new; the atomic check-and-record at the gate is kept. Test extended.
### prow-analyzer — fix dedup window shorter than max analysis (concurrent double-run)
- Bug: the fixed 10-min `dedupTTL` was shorter than a max analysis (up to the configurable MCP timeout), so a late duplicate event could expire the entry and spawn a second, concurrent analysis of the same job.
- Fix: `dedupTTL = analyzer.MCPTimeout() + 5-min grace`, floored at 10 min; exported `analyzer.MCPTimeout()`. Dedup remains per-pod in-memory. Tests added.
### prow-analyzer — configurable debug logging and TLS verification via flags/env
- Added `--slack-debug` (env `SLACK_DEBUG`) and `--tls-insecure` (env `TLS_INSECURE_SKIP_VERIFY`) bot flags; previously debug was hardcoded on and TLS-skip was read only from the env var.
